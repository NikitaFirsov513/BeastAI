# BeastAI

Обнаружение животных на дневных цветных снимках с воздуха. Сейчас работаем с готовой DroneMegaDetector; прежняя компактная YOLO и результаты экспериментов сохранены для сравнения.

Рабочая папка: `D:\PROJECTS\PYTHON\BeastAI`. Данные, модели, окружения и загрузки находятся здесь, на диске D.

## Запуск

- **Рамки поверх видео и окон Windows:** двойной щелчок по [start_screen_overlay.cmd](start_screen_overlay.cmd). Выбрать область → «Старт»; F8 останавливает захват. [Инструкция](docs/SCREEN_OVERLAY.md).
- **Просмотр снимков, разметки и результатов:** [start_preview.cmd](start_preview.cmd), затем http://127.0.0.1:8765/ .
- [Сравнение DroneMegaDetector и YOLO](data/dronemegadetector/evaluation/COMPARISON.md). Это диагностика; качество на новых полётах ещё не подтверждено.

## Где что лежит

| Папка | Содержимое |
|---|---|
| `src/` | Код приложений, поиск животных, просмотр и общие функции |
| `assets/` | HTML-интерфейс веб-просмотра |
| `scripts/data/` | Загрузка, отбор и подготовка данных |
| `scripts/training/` | Обучение и запуск учебных экспериментов |
| `scripts/evaluation/` | Автоматическое сравнение предсказаний с разметкой и проверки просмотра |
| `scripts/diagnostics/` | Разбор ошибок, маленьких животных и скорости |
| `scripts/publishing/` | Формирование отчётов и публикация результатов в просмотре |
| `scripts/maintenance/` | Исторические разовые изменения интерфейса; повторный запуск обычно не нужен |
| `tests/` | Проверки кода |
| `docs/` | Требования, план, инструкции и история экспериментов |
| `launchers/` | Дополнительные CMD-файлы, включая старые эксперименты |
| `data/` | Изображения, разметка, веса, отчёты и кэши; [указатель](data/README.md) |
| `backups/` | Резервная копия файлов до уборки |

## Запуск скриптов из PowerShell

Открыть PowerShell в папке проекта. Для этой уборки устанавливать программы не требуется.

```powershell
.\.venv\Scripts\python.exe run.py --list
.\.venv\Scripts\python.exe run.py test
```

Первая команда показывает скрипты, вторая запускает существующие проверки. Любой прежний скрипт запускается через `run.py имя_скрипта` с прежними аргументами. Например:

```powershell
.\.venv\Scripts\python.exe run.py waid serve --dataset sherbrooke
```

Для DroneMegaDetector и программы с рамками используется её отдельное окружение:

```powershell
.\data\dronemegadetector\env\Scripts\python.exe run.py screen_overlay
```

Названия команд можно указывать с `.py` или без. `run.py` задаёт рабочую папку и пути импорта, поэтому скрипты находят прежние данные. Обучение и скачивание запускаются только выбранной командой; список команд ничего не запускает.
