# Просмотрщик WAID

Программа скачивает оригинальные цветные снимки и соответствующие текстовые файлы рамок, хранит их отдельно и накладывает разметку в браузере. Рамки взяты из датасета, нейросеть ещё не запускается. Требуется Python 3.10 или новее; дополнительные библиотеки не нужны.

## Первый запуск

Дважды нажмите `start_preview.cmd` в этой папке. Он загрузит 30 пар «снимок + разметка» и откроет локальный просмотрщик. Окно программы оставьте открытым. Остановить просмотрщик можно сочетанием Ctrl+C в этом окне.

В браузере доступны переключатели рамок и категорий, увеличение снимков, поиск по имени, фильтр по части набора и страницы по 12 снимков. На увеличенном снимке переключатели продолжают действовать; закрытие — Esc. Рамки не записываются в исходные фотографии.

## Файлы

```text
data/waid/
  index.json         — версия источника и полный список файлов
  images/
    train/           — исходные изображения
    valid/
    test/
  labels/
    train/           — отдельные текстовые файлы разметки
    valid/
    test/
```

Имена изображения и его разметки совпадают, расширения отличаются. Строка разметки: `категория центр_x центр_y ширина высота`. Последние четыре числа выражены долями размеров изображения. Категории пока сохранены как в оригинальном наборе; объединение в `animal` будет отдельным шагом подготовки к обучению.

## Полный набор

`download_all.cmd` скачивает **все пары** текущей зафиксированной версии WAID. Не запускайте его для первого знакомства, если достаточно 30 снимков. Точный размер и число файлов показывает команда `python waid.py inspect`. Архив и история Git не скачиваются. Повторная загрузка проверяет содержимое по контрольным суммам Git и пропускает исправные файлы; повреждённые скачивает заново. Незавершённые файлы имеют расширение `.part` и не появляются в просмотрщике.

После дополнительной загрузки перезапустите просмотрщик, чтобы он увидел новые снимки.

## Команды для PowerShell

Рабочая папка проекта: `D:\PROJECTS\PYTHON\BeastAI`. Откройте PowerShell и выполните `cd D:\PROJECTS\PYTHON\BeastAI`. Затем выполняйте команды по отдельности:

```powershell
python waid.py inspect
python waid.py download --limit 30
python waid.py serve --open
```

Первая команда получает только список файлов и показывает размер полного набора. Вторая скачивает небольшую повторяемую выборку из трёх исходных частей. Третья запускает просмотрщик на `http://127.0.0.1:8765/`, доступный только на этом компьютере. Другой порт: `python waid.py serve --port 8766 --open`.

## Границы текущего шага

Выборка из 30 снимков предназначена для осмотра, а не для оценки качества. Сохраняется исходное разделение train/valid/test; его независимость по полётам ещё не проверена. Категории и исходная разметка не меняются. Пустой файл, отсутствующая разметка и неверные строки различаются в интерфейсе. Неверные строки не рисуются; показывается сообщение об ошибке.

При первом запуске нужен доступ к `api.github.com` и `raw.githubusercontent.com`. При сетевом сбое можно повторить запуск: завершённые загрузки сохраняются. После скачивания просмотрщик работает без интернета.

Источник: https://github.com/xiaohuicui/WAID. Программа фиксирует версию репозитория в `index.json` и получает все файлы из этой версии.
