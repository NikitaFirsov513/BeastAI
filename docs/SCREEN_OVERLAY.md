# Рамки животных поверх окон Windows

Запуск: двойной щелчок по `D:\PROJECTS\PYTHON\BeastAI\start_screen_overlay.cmd`.
Используется уже подготовленное окружение `data/dronemegadetector/env` и существующие веса; дополнительных загрузок при запуске нет.

1. Открой цветное видео в браузере или плеере.
2. В панели BeastAI нажми «1. Выбрать область видео» и обведи только картинку видео. Esc отменяет выбор.
3. Нажми «2. Старт». Дождись загрузки модели. F8 или кнопка «Стоп» прекращают захват и убирают рамки.

Панель можно переместить за пределы видео. Область закреплена в координатах экрана: после перемещения/изменения размера видео выдели её снова. Если другое окно закроет видео, программа увидит новое содержимое выбранного прямоугольника. Защищённое или эксклюзивное полноэкранное видео может не захватываться; обычный оконный режим предпочтительнее.

По умолчанию выбран DroneMegaDetector, вход1280, FP32, порог0,25, не чаще3 кадров/с. Доступна прежняя YOLO11n с входом1024. Изменять модель/порог/частоту можно после остановки. Качество моделей имеет прежние ограничения: новая оболочка не исправляет пропуски и ложные обнаружения. Это ещё не трекер, поэтому на движении рамки могут отставать.

## Как устроено

- Поверх выбранного прямоугольника находится прозрачное окно, пропускающее клики. Панель управления остаётся отдельным обычным окном.
- Захват выполняется локально только для выбранной области, через повторно используемый Windows GDI DIB/BitBlt. Изображение передаётся в существующий детектор; обрабатывается класс animal, люди/машины готовой модели не показываются. Порог применяется до дополнительного удаления повторов IoU0,5.
- Собственные рамки исключены из захвата через WDA_EXCLUDEFROMCAPTURE и отсутствие CAPTUREBLT. На собственном статичном снимке проверено совпадение нового захвата с Pillow и отсутствие обратного попадания рамок: `data/screen_overlay/demo_capture_check.json`.
- В каждый момент обрабатывается один снимок, очередь результатов хранит только последний. Новый кадр берётся после предыдущей обработки; ограничения кадров/с — максимум, не обещание этой скорости.
- Результаты старше1 секунды скрываются. Остановка немедленно убирает рамки и запрещает новые захваты; текущий вызов модели завершается. GPU-память модели освобождается после остановки. Программа не требует прав администратора и блокирует случайный запуск второго экземпляра.
- Кадры не записываются и не отправляются в сеть. В `data/screen_overlay` сохраняются технический журнал и числовые замеры; измерения ограничены последними600 обработанными кадрами и120 показанными результатами, чтобы память не росла бесконечно.

## Замеры прототипа

На RTX4060 Laptop, выбранная область1024×683, DroneMegaDetector1280/FP32, пакет1, порог0,25 и ограничение3 кадров/с: в последовательных пробах медиана захвата составила226,6мс с Pillow (захват всего виртуального рабочего стола с последующим обрезанием) и78,6мс с GDI только для нужной области. Медиана «захват → готовые рамки»428,9→320,3мс. Последние120 команд отрисовки в новой пробе: медиана402,8мс, p95612,0мс. Питание/нагрузка ОС не зафиксированы; это функциональные замеры, не строгое доказательство постоянного ускорения. Энергия не измерена, будущая плата1TOPS не проверяется.

Таймер интерфейса включает захват, подготовку, модель, обработку рамок, ожидание главного потока и подачу команд отрисовки. Он не измеряет момент появления пикселей на физическом мониторе. Загрузка модели и прогрев исключены; первый запуск может быть заметно дольше. Отдельного измерения задержки воспроизведения самого видео нет. Число показанных рамок не является оценкой качества.

Проверка на своём снимке: запуск модели, прохождение клика к нижнему окну, остановкаF8, исключение собственных рамок, совпадение цветов/координат захвата. Сценарии с отрицательными координатами монитора покрыты тестом геометрии; все реальные конфигурации нескольких мониторов не проверялись. Диагностический запуск собственного тестового окна: `data\dronemegadetector\env\Scripts\python.exe run.py screen_overlay --demo` из папки проекта.

Программа: `src/screen_overlay.py`; Windows-захват и стили: `src/screen_overlay_win32.py`. Ошибки: `data/screen_overlay/overlay.log`. Закрой панель для выхода; во время загрузки/текущего вычисления дождись их завершения.
